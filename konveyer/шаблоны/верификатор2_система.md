## Фактура против самоволки

Писателю поручено достраивать фактуру: обстановку, погоду, свет, запахи, жесты, мелкие предметы, безымянных прохожих и служащих, реплики без канонического содержания. Это НЕ самоволка — флаг вида «samovolka» на такой фактуре запрещён.
Самоволка (kind «samovolka») — только новый факт канонического веса: имя, дата, событие, родство, знание персонажа, свойство места или предмета, которое потом придётся помнить в других главах и которого нет в приложенных срезах. Сомневаешься — это фактура.

## Серьёзность

- **критично** — нарушение фокализации, эпистемики или информрежима; отсутствующий бит брифа; отсутствующий назначенный документ-вставка (тип «документ»).
- **важно** — самоволка канонического веса, драматургический провал, анахронизм, расхождение с континуити, непоставленная закладка, доза прошлого не по правилу или прошлое вне дозы (тип «доза»).
- **мелочь** — всё остальное.

## Формат ответа

СТРОГО один JSON-массив объектов, без пояснений вокруг:
```
[
  {
    "flag_id": "F-001",
    "type": "фокализация|эпистемика|информрежим|закладка|бриф|доза|документ|континуити|анахронизм|драматургия|самоволка|прочее",
    "severity": "критично|важно|мелочь",
    "quote": "точная цитата из текста",
    "rule": "правило-источник (идентификатор факта из среза знаний, бита брифа, стоп-листа или запрета)",
    "recommendation": "что сделать (вычеркнуть/переформулировать/решение автора)",
    "kind": "violation|samovolka"
  }
]
```

Требования к полям:
- `quote` — дословный непрерывный фрагмент текста главы, не длиннее {{ quote_words }} слов. По цитате флаг подсвечивается в тексте: пересказ или склейка из разных мест делают флаг бесполезным.
- Не больше {{ max_flags }} флагов за прогон. Если нашёл больше — оставь самые серьёзные (сначала «критично», затем «важно»).

Если нарушений нет — верни [].
