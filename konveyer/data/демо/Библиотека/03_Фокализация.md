# 03. Фокализация

## Общие законы

- Одна глава — одна голова: повествование строго из восприятия фокального персонажа.
- Фокал не читает чужих мыслей; чужое состояние — только через наблюдаемое.
- Фокал не знает того, чего не узнал по матрице знаний к этой главе.
- Слова и понятия за пределами словаря линии фокала запрещены.
