# ИНСТРУМЕНТ_Соглашения_разметки (Д-1)

Соглашения структуры MD-библиотеки, под которые написан парсер конвейера.
Канон не переформатируется под парсер — парсер пишется под канон; при изменении
фактической структуры библиотеки правится ЭТОТ документ и код `konveyer/exporter.py`.

## Общие правила

- Кодировка UTF-8, файлы Markdown (NFR-8).
- Таблицы — pipe-таблицы GFM: строка заголовков, строка-разделитель `|---|`, строки данных.
- Пустые значения в ячейках: `—` (длинное тире) или пусто.
- Маркеры статусов в реестрах: `⚠` (внимание), `✓` (закрыто/положена), `🔧` (в работе).
- Ссылки на решения журнала: `Р-№` (например Р-016). Изменение норм — только при записи в `36_Журнал` (сценарий Б).

## Документы-вставки в прозе (Д-7)

Блок, исключаемый из метрик повествователя, размечается строками-маркерами:

```
→ ДОКУМЕНТ
…текст документа (справка, письмо, протокол)…
← КОНЕЦ ДОКУМЕНТА
```

## 02_Стиль_и_голос.md

- Секции `## §1…§4`, `## §6.1`, `## §6.2` — включаются в окно (раздел «регистр и стиль»).
- `## §5. Численные нормы` — таблица с колонками `id | параметр | мин | макс | брак | единица`.
  Единственный источник порогов Э1 (в коде констант нет). Обязательные id:
  `средняя_длина, доля_коротких, доля_длинных, максимум_длины, короткая_фраза_порог,
  длинная_фраза_порог, был_на_250, усилители_на_1000, ttr_окно_слов, ttr_мин,
  объём_допуск, утечка_нграмма, повтор_нграмма`.
- Секция со словом «усилител» в заголовке — таблица `| слово |`: словарь наречий-усилителей (Р-016).

## 03_Фокализация.md

- Секция `## Общие законы` — текст, включается в окно целиком.
- Таблица стоп-листов линий: `rule_id | фокал | слова/обороты | действие`.
  Слова разделяются `;`. Фокал `все` = правило всех линий. Действие: `запрет` | `флаг`.

## 04_Лексика_эпохи.md

- Таблица: `rule_id | слова/обороты | годы | действие`.
  Формат «годы»: `до 1999`, `1990–1999` или `все`.

## 2.2_Информрежим.md

- Таблица: `ban_id | запрет | до тома`.

## 23_Поглавник_ТомN.md

Каждая глава — секция `## Глава N — Название` со списком ключей:

```

- Год: 1995
- Фокал: Каширин
- Участники: 
  - Каширин
  - Зоя
- Объём: 4500

  - …
- Биты:
  - …
- Запреты:
  - НЕ упоминать …
- НЕ знает:
  - …
- Закладки: P-001; P-002
```

## 31_Матрица_знаний.md (реестр 3.1)

Таблица: `fact_id | факт | субъект | узнаёт в главе | источник | примечание`.
`узнаёт в главе` = номер главы или `—` (субъект НЕ знает).

## 32_Реестр_закладок.md (реестр 3.2)

Таблица: `plant_id | что | положена | выстрел | статус`.
Формат места: `т1 гл3`; несколько выстрелов через `;` (`т1 гл9; т2`).

## 33_Хронология.md (реестр 3.3)

Таблица: `дата | событие | главы | примечание`.

## 36_Журнал_решений.md (журнал 3.6)

Записи решений `Р-№`; формат свободный, ссылки Р-№ проверяются в сообщениях коммитов.

## Досье/*.md (реестр 1.2)

Один файл — один персонаж. `# Имя`, секции `## Профиль` (2–3 строки), `## Физика`,
`## Речевой паспорт`, `## Отношения` (таблица `к кому | отношение`).

## Проза/

Принятые главы: `ТомV_ГлаваNN.md`. Только проза и маркеры документов-вставок.
