# КОНВЕЙЕР

Универсальный производственный конвейер книжной серии: библиотека канона в Markdown → выгрузки →
окно главы для Писателя → формальные и смысловые проверки → приёмка автора → записи в канон.
Любая серия описывается манифестом проекта и каталогом типов документов; в коде нет ничего серийного.

- Руководство автора — [Запуск.md](Запуск.md).
- Карта проекта для разработчика — [CLAUDE.md](CLAUDE.md).
- Соглашения типов документов и реестр метрик — [docs/](docs/) (генерируются командой `konveyer типы --документация`).

```
pip install -e ".[llm,dev]"
konveyer проект создать ~/Серия --имя "Моя серия" --томов 3
konveyer доктор
konveyer такт 1
```

Тесты: `PYTHONUTF8=1 python -m pytest tests/ -q`; линт: `ruff check konveyer tests`.
