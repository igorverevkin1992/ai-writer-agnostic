# CLAUDE.md

Проект: агент для сценариев вертикальных микросериалов. Полное ТЗ — SPEC.md.
Пользователь — продюсер, не программист. Отчёты ему — простым русским языком,
коротко, одна задача за раз.

## Правила кода
- TypeScript strict, pnpm workspaces. Новые зависимости — только если без них никак.
- Код, имена, комментарии — на английском. Тексты UI и промпты агента — на русском.
- Любой ответ модели — JSON, проверенный Zod-схемой.
- Идентификаторы моделей — только в config/models.yaml.
- Правила жанра — только в packages/kb. Не зашивать их в код или промпты.
- Продукт — для любых сериалов, не для одного. Всё, что зависит от жанра, формата
  или площадки, — данные жанрового пакета (packages/kb/genres/<id>.yaml и файлы,
  на которые он ссылается). Всё, что относится к конкретному сериалу, — данные
  проекта. В коде нет ни имён героев, ни числа серий, ни числа злодеев.
- Проверяющий всегда другого семейства, чем автор текста. Это правило не ослаблять.
- Тесты не вызывают реальные API. Реальные вызовы — только pnpm smoke и pnpm eval.
- Ключи — только в .env. Не коммитить .env и папку data/.

## Порядок работы
- Работай по вехам из SPEC.md, по одной. Следующую — только после подтверждения продюсера.
- Перед закрытием вехи: pnpm lint && pnpm test.
- После вехи — отчёт: что готово, как проверить за 5 минут, что дальше.
- Творческие и бизнес-вопросы — продюсеру. Технические — решай сам.

## Команды
- pnpm dev — запуск приложения
- pnpm test — тесты
- pnpm smoke — по одному реальному вызову на каждую роль
- pnpm eval — оценка аудитора на золотом наборе и посеянных дырах
