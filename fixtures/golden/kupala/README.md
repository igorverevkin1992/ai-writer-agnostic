# Золотой набор: «Муж утопил меня в Купальскую ночь» (ромэнтэзи, эталон продюсера)

Эталонный проект жанра `romantasy_revenge` от продюсера (30.09.2026). Это данные проекта, а не правила.

- `concept.md` — концепт продюсера целиком (из Claude Docs).
- `review_fable.md` — эталонный разбор дыр (Fable 5.1): 68 дыр, таблица знания персонажей, счётчик дней,
  посадки и окупаемости, вопросы и ответы юриста, три самых опасных места. Так должен выглядеть
  разбор агента. Промпт разбора — `docs/hole_review_prompt.md`.
- `holes.yaml` — те же 68 дыр как эталонный список для `pnpm eval`: категория А–П, серьёзность,
  что не сходится, почему заметят, как закрыть, правило для агента.
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий **точно по концепту, со всеми его дырами**.
  Их не исправляют: на них агента сверяют с эталонным разбором.

Чистый эталон жанра для проверки кода и посева дыр — `fixtures/golden/naslednitsa`.

Проверить на реальных моделях (когда будут ключи):
`pnpm eval --project=kupala --genre=romantasy_revenge --seeded=none`.
