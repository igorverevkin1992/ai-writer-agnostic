# Золотой набор: «Три луны» (тёмное славянское фэнтези-миф, эталон продюсера)

Эталонный проект жанра `slavic_myth` от продюсера (концепция, версия 2, 02.10.2026). Это данные проекта,
а не правила.

- `concept.md` — концепция продюсера целиком (из docx).
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий **точно по концепции, со всеми её дырами**.
  Событие, обрыв и тип обрыва в плане — из карты сезона дословно; разметку для проверок
  (опорные точки, удары, настроение) расставил Claude Code. Годы условные: действие — 1100 год.
- `demo.yaml` — ответы демо-режима для проектов этого жанра.
- `holes.yaml` — **ждём**: эталонный разбор дыр (как у «Купальской ночи»).

Что код находит уже сейчас (без моделей):
- законов леса 7, а жанр разрешает 1–3;
- платный барьер в 8-й серии и ответ в 9-й, а каркас жанра — 10-я и 11–12-я;
- пересчёт правил в 4-й (каркас — 5-я), спутник платит цену в 30-й (каркас — 31–36-я);
- после побед над кикиморой (8) и водяным (18) нет ответного удара;
- три «Откровения» подряд (25–27), хотя концепция сама требует разные типы обрыва подряд.

Проверить на реальных моделях (когда будут ключи):
`pnpm eval --project=tri_luny --genre=slavic_myth --seeded=none`.
