# Золотой набор: «Три луны» (тёмное славянское фэнтези-миф, эталон продюсера)

Эталонный проект жанра `slavic_myth` от продюсера (концепция, версия 2, 02.10.2026). Это данные проекта,
а не правила.

- `concept.md` — концепция продюсера целиком (из docx).
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий **точно по концепции, со всеми её дырами**.
  Событие, обрыв и тип обрыва в плане — из карты сезона дословно; разметку для проверок
  (опорные точки, удары, настроение) расставил Claude Code. Годы условные: действие — 1100 год.
- `demo.yaml` — ответы демо-режима для проектов этого жанра.
- `fixes.md`, `fixes.yaml` — 58 исправлений скрипт-доктора «было / стало / почему», которыми версия 1
  концепции стала версией 2. «Почему» — правила для агента: они перенесены в общий метод разбора
  (`packages/kb/review/review.yaml`) и в подсказки жанра (`packages/kb/guides/slavic_myth.yaml`).
  Версия 1 и разбор скрипт-доктора — в `fixtures/golden/tri_luny_v1` (набор для проверки агента).
- `holes.yaml` — нет: версия 2 уже исправлена по разбору.

Барьер после 8-й, правила в 4-й, плата спутника с 30-й и законы без лимита числа (если у каждого есть серия,
где его произносят, и серия, где он срабатывает) — по решению продюсера 03.10.2026 стали правилами жанра.

Что код находит в версии 2 (без моделей):
- после побед над кикиморой (8) и водяным (18) нет ответного удара;
- обрывы одного типа подряд в 13–14, 23–24, 25–27, 29–30, 54–55, хотя концепция сама требует разные типы подряд;
- Василисе семь, а Гордей ушёл на войну десять лет назад, когда Любава уже была беременна (это код не ловит, нашёл Claude Code при сборке хронологии).
