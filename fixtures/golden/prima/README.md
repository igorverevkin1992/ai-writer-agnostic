# Золотой набор: «Прима» (вертикальный триллер, саспенс и хоррор, эталон)

Эталонный проект жанра `vertical_thriller`. Написан Claude Code 15.10.2026 по документу продюсера «Как придумать
вертикальный триллер, саспенс или хоррор» (пересказ двух исследований октября 2026) — как образец того, что
софт ждёт от концепта этого жанра. Это данные проекта, а не правила. Доработан 22.10.2026 по двум прогонам
аудитора: 25 вопросов разбора закрыты в тексте (см. `concept.md`, «Закрытые вопросы разбора»); версия для
коллег — `docs/Прима — концепт.docx`.

- `concept.md` — концепт для чтения: логлайн, ствол и матрёшка, угроза, персонажи, ставки, правила, улики,
  сетка сезона и карта по сериям.
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий. Корректные: проходят все кодовые проверки жанра
  (ствол и матрёшка, улики, знак угрозы, «Золотые 3», барьер «В+У+Л», перезагрузки, режим знания,
  словарь обрывов, арка, цена побед, три ставки). Основа для демо-режима и посева дыр.
- `demo.yaml` — ответы демо-режима для проектов этого жанра.
- `holes.yaml` — нет: это чистый эталон. Набор для проверки аудитора — `fixtures/golden/prima_v1` (28 намеренных дыр).

Параметры: 60 серий по 90 с, барьер после 10-й (входной параметр каркаса `thriller60`), гибрид «триллер + семья».

Проверить на реальных моделях (когда будут ключи):
`pnpm eval --project=prima --genre=vertical_thriller --seeded=none`.
