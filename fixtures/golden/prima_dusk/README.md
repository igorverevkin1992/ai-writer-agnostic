# Золотой набор: «Прима. Сумерки» (вертикальный триллер, мистическая версия)

Второй эталонный проект жанра `vertical_thriller`. Написан Claude Code 22.10.2026 по брейнсторму продюсера:
«Покровка. Театр», спектакль «Москва. Сумерки», бабка-хранительница дома, снадобье из крови молодых,
прима, которая не стареет тридцать лет. В отличие от `prima`, мистика здесь настоящая и живёт по правилам
мира с ценой (четыре правила). Это данные проекта, а не правила жанра.

- `concept.md` — концепт для чтения: логлайн, ствол и матрёшка, угроза и механика снадобья, персонажи,
  ставки, правила, улики, календарь, сетка сезона, карта по сериям.
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий. Корректные: проходят все кодовые проверки жанра.
  Шесть постоянных персонажей (Ася, Марго, Нюра, Марк, Семён, Вика) и два эпизодических (Инга, Лёва).
- `demo.yaml` — нет: демо-режим жанра отвечает по `prima`.
- `holes.yaml` — нет: это чистый эталон.

Параметры: 60 серий по 90 с, барьер после 10-й (каркас `thriller60`), гибрид «мистический триллер + дружба».
Версия для коллег — `docs/Прима. Сумерки — концепт.docx`.

Проверить на реальных моделях:
`pnpm eval --project=prima_dusk --genre=vertical_thriller --seeded=none`.
