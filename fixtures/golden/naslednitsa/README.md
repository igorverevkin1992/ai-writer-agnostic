# Золотой набор: «Наследница Вороновых» (ромэнтэзи с реваншем)

Эталонный проект жанра `romantasy_revenge`. Собран Claude Code по карте сезона из исследования
продюсера «Ромэнтэзи с реваншем и наказанием подлеца» (30.09.2026). Это данные проекта, а не правила:
ни код, ни база знаний на этот сериал не опираются.

Имена по решению продюсера: семья Туманских (в исследовании — Орловы), начальник безопасности
Савелий Дёмин (в исследовании — Штерн).

- `concept.md` — концепция: логлайн, герои, чудо, злодеи, три линии сезона.
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий. Проходят все кодовые проверки жанра.
  На их основе `pnpm seed-holes --project=naslednitsa --genre=romantasy_revenge` сеет дыры
  (`fixtures/seeded/naslednitsa.yaml`).
- `demo.yaml` — ответы демо-режима для проектов этого жанра.
- `holes.yaml` — **ждём от продюсера**: дыры, найденные вручную, в формате
  `{holeType, episode, description}`.

Проверить на реальных моделях (когда будут ключи):
`pnpm eval --project=naslednitsa --genre=romantasy_revenge`,
`pnpm pilot --project=naslednitsa --genre=romantasy_revenge`.
