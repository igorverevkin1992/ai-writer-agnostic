# Золотой набор: «Три луны», версия 1 (фэнтези-миф) и разбор скрипт-доктора

Первая версия концепции продюсера и её разбор (01.10.2026). Это набор для проверки агента: на нём видно,
найдёт ли агент те же дыры, что скрипт-доктор. Исправленная версия — `fixtures/golden/tri_luny`.

- `concept.md` — концепция версии 1 целиком.
- `review_doctor.md` — разбор скрипт-доктора: 12 противоречий, 47 дыр по 12 проверкам, исторические
  мелочи, топ-5, исправленная карта, правила-проверки для агента.
- `holes.yaml` — те же дыры как эталонный список для `pnpm eval`: категория А–П, тяжесть, где, что не так,
  почему заметят, как закрыть, правило для агента (из пар «было / стало», `tri_luny/fixes.yaml`).
- `bible.yaml`, `plan.yaml` — библия и план на 60 серий **точно по версии 1, со всеми её дырами**.
  Строка карты на несколько серий даёт несколько серий с одним событием и без своего обрыва — как в концепции.

Проверить на реальных моделях (когда будут ключи):
`pnpm eval --project=tri_luny_v1 --genre=slavic_myth --seeded=none`.
