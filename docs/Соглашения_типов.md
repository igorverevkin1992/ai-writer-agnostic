# Соглашения типов документов

Документ сгенерирован из каталога типов движка (`konveyer типы --документация`). Здесь описано, что именно машина читает из документа каждого типа, что попадает в окно Писателя и какие проверки линтера тип включает. Канон не переформатируется под парсер: имена колонок и секций сопоставляются в манифесте проекта (`проект.yaml`, блок `библиотека`).

## акты

- Назначение: Акты (части) тома: границы глав и названия
- Множественность: по_тому; имя по умолчанию `21_Акты_Том{том}.md`
- Питает модули: драматургия, линтер
- Обязателен для первого такта: нет
- Извлечение «акты» → `acts.json`:
  - таблица: колонки акт (акт/часть/№), название (название/имя), главы (глав), части (части), шаги (шаг)
- Проверки линтера: АКТ-1, ЧАСТЬ-1
- Сигнатуры классификации: имя_файла: ['акт', 'части']; колонки: ['акт', 'главы']; заголовки: ['акты', 'части']

## арки

- Назначение: Арки персонажей по актам: ложь, желание, потребность, положение на арке, что видно снаружи
- Множественность: по_тому; имя по умолчанию `22_Арки_Том{том}.md`
- Питает модули: окно, драматургия, арки
- Обязателен для первого такта: нет
- Извлечение «арки» → `arcs.json`:
  - таблица: колонки персонаж (персонаж/герой), акт (акт), ложь (ложь), желание (желание/хочет), потребность (потребность/нужно), положение (где на арке/положение/где), видно (видно снаружи/видно/снаружи)
- В окно Писателя: только «что видно снаружи» для участников сцены по акту главы; запрещено показывать: ложь, желание, потребность, положение на арке
- Проверки линтера: АРКА-1, АРКА-2
- Сигнатуры классификации: имя_файла: ['арки', 'арок', 'arcs']; колонки: ['ложь', 'желание', 'потребность']; заголовки: ['арки', 'арка ', 'арок']
