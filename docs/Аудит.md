# Аудит проекта и план исправлений

Дата аудита: 23–24 сентября 2026. Объект: репозиторий `konveyer` на коммите b373ac2 (после этапа 7). Основание: ТЗ «Универсальный конвейер книжной серии» v1.0.

## Метод

Аудит шёл по 20 измерениям: 11 — сверка каждого раздела ТЗ (§1–§16, приложения) с кодом и тестами, 5 — корректность кода по зонам (крайние случаи, воспроизведение на копии демо-проекта), 4 — тесты, данные пакета, документация и упаковка. Каждое измерение вёл отдельный агент в режиме только чтения; каждая находка содержит файл, строку, доказательство (вывод скрипта или цитату) и предложение исправления. Три измерения (документация, П-1 и профиль, упаковка/CI) и одно измерение корректности кода (шаги, CLI, git, бэкап) не завершились из-за внешних лимитов; их задачи переданы в соответствующие кластеры исправлений как «проверь и исправь сам».

Исправления идут кластерами по файлам: каждый кластер — своя ветка `аудит/<кластер>`; агент сначала воспроизводит находку, затем чинит, покрывает тестом и коммитит. Находки, которые не подтвердились, противоречат ТЗ или требуют решения автора (§15 ТЗ), отклоняются с причиной. Затем ветки сливаются, прогоняется полный набор тестов и сборка панели.

### Слияние веток

Тринадцать веток исправлений писались параллельно от одного исходного коммита и пересекались в общих файлах.
При слиянии конфликты разрешались с сохранением намерений обеих сторон; где два набора тестов требовали
взаимоисключающего поведения, выбрано поведение по ТЗ, а второй тест приведён к нему:

- `konveyer статус N` для главы вне плана — ошибка номера (код 1), как 404 в панели.
- Стоп-лист линии, слово которого совпадает с маркером недоступной фокалу тайны, в окно не идёт целиком
  (иначе правило само подсказывает тайну); Э1 проверяет его по выгрузке.
- Коммит приёмки узнаётся по трейлеру `Конвейер-приёмка: глава N; том V` в теле сообщения; тома ≥ 2 различаются.
- Русификация командной строки — одна реализация в `cli.py`; дублирующий слой подмены gettext убран.
- Тесты на живой библиотеке эталона собраны в `tests/профиль_угар` с общими фикстурами; в CI библиотека
  клонируется (переменная `KONVEYER_ETALON`), без неё тесты пропускаются с пометкой.

Итог после всех слияний: `ruff check konveyer tests` чисто; `pytest` — 974 теста зелёные, 2 пропуска по окружению;
тесты фронтенда панели (`npm test`) — 12 зелёных; панель пересобрана.
