# База знаний

Все правила жанра, методики и ограничения живут здесь как данные. Код и промпты их только читают.

## Жанровые пакеты: один продукт — много сериалов

Каждый проект (сериал) выбирает жанровый пакет из `genres/`. Пакет говорит, какие файлы
действуют для этого жанра и формата: правила, каркас сезона (число серий, бесплатные серии,
опорные точки, лестница злодеев), чек-лист, персоны зрителей, правовые и производственные рамки.

- **Новый сериал в том же жанре** — просто новый проект. Ничего добавлять не нужно.
- **Новый жанр или формат** (например, 30 серий без злодеев) — новый файл `genres/<id>.yaml`
  и свои `rules/`, `frames/`, `checklist/`. Код не меняется.
- Всё, что относится к конкретному сериалу (герои, мир, тайна), — данные проекта, не базы знаний.
  Эталонный концепт «Муж женился на мне ради крови» лежит в `fixtures/golden/`.

| Файл | Что внутри | Состояние |
|---|---|---|
| `genres/revenge_thriller.yaml` | Жанровый пакет «триллер мести» | готов |
| `rules/revenge_thriller.yaml` | Правила жанра R01–R18 | из ТЗ v2 |
| `frames/season60.yaml` | Каркас сезона из 60 серий | полностью из ТЗ |
| `checklist/season20.yaml` | Чек-лист на 20 баллов | из концепции продюсера, 9 пунктов |
| `methods/*.yaml` | Вейланд, Труби, Хармон, Моуэри | заглушки |
| `glossary.yaml` | Кайф, страдание, поворот… | заглушка |
| `constraints/ru_legal.yaml` | Правовые рамки и слова-маркеры | принципы из ТЗ, маркеры — заглушка |
| `constraints/production.yaml` | Производственные лимиты и метрики сценария | полностью из ТЗ |
| `holes/catalog.yaml` | 11 типов дыр и вопросы | полностью из ТЗ |
| `personas/viewers.yaml` | 5 персон зрителей | состав из ТЗ, описания — заглушка |
| `cases/*.yaml` | Свои пересказы эталонов | пример формата |
| `prompts/<роль>/<шаг>.md` | Промпты | заглушки |

Файлы с `stub: true` ждут материалов продюсера. Когда файл заполнен, `stub` убирают:
например, у чек-листа тогда сумма баллов обязана быть ровно 20.

Проверить базу после правки: `pnpm kb:check`. Ошибка покажет файл, строку и поле.
