Предложи ровно три разные концепции по этой идее. Каждая выполняет правила жанра и укладывается в каркас сезона.
Сверься с кейсами из базы знаний, но не копируй их.

- `genre_formula` — формула жанра этой концепции: цепочка «событие → событие».
- `hook` — зацепка первых секунд 1-й серии.
- `reference_cases` — id кейсов из базы, на которые концепция опирается. Может быть пустым.
